# Crimsonland custom quests: `.quest` reference

A complete reference for writing `.quest` recipes for the Crimsonland rebuild (github.com/banteg/crimson): the grammar, what the grammar leaves unsaid, the numbers you need to balance an encounter, and the toolchain. Published quests: crimson.land/custom.

## Model

A recipe is a construction-time program. It runs once, before play, and emits a table of 1..256 entries `(template, x, y, heading, trigger_ms, copies)`, which the original game's quest scheduler plays. It has no callbacks during play, so it cannot change creature behaviour, collision, the arena or the objective. Templates are the original game's spawn templates, with their native health, AI, formations and offspring.

Scheduler, every frame:

- It finds the first entry in table order whose trigger time has passed, then spawns it together with the entries *immediately after it* that share its exact `trigger_ms`. Same-time entries split by an entry with another time arrive on separate frames, and a backlog of due groups drains one group per frame.
- An entry's copies spawn in a line through its point, 40 units apart on alternating sides (offsets 0, -40, +80, -120, ...). The line runs along x, or along y when the point lies off the west or east side (x < 0 or x > 1024).
- If no creature has been alive for 3 s (and the clock is past 1.7 s), the next remaining entry in table order spawns immediately, whatever its time. Fast clears therefore pull the timeline forward; `order` decides what gets pulled.
- The quest is won when every entry has spawned and no creature is alive, nests included. There is no time limit, no fail-by-timeout and no other objective. The player loses by dying (100 HP).

Custom quests always build with `players = 1`, `hardcore = false` and construction seed 0, and always play the ranked profile: one player, every quest unlocked, original bugs fixed. `rand()` is deterministic, so a recipe always produces the same table.

## Grammar (verbatim `quest.lark`, Lark LALR with an indenter)

```lark
start: _NL? header setting* statement*

header: "quest" STRING "version" INT _NL

?setting: "author" STRING _NL -> author
        | "order" ORDER _NL -> order
        | "weapon" NAME _NL -> weapon
        | "terrain" "(" INT "," INT "," INT ")" _NL -> terrain
        | "no_bonuses" name_list _NL -> no_bonuses
        | "no_perks" name_list _NL -> no_perks
        | "no_weapons" name_list _NL -> no_weapons
        | "fixed_weapon" boolean _NL -> fixed_weapon

boolean: "true" -> true | "false" -> false
name_list: "[" (NAME ("," NAME)* ","?)? "]"

?statement: simple _NL | compound

?simple: "let" NAME "=" expr -> let
       | "var" NAME "=" expr -> var
       | NAME "=" expr -> assign
       | NAME update_op expr -> update
       | "spawn" expr "at" expr ["copies" expr] ["heading" expr] -> spawn
       | "burst" expr "at" expr "copies" expr ["heading" expr] -> burst
       | "place" expr "on" expr ["copies" expr] ["heading" expr] -> place
       | NAME "(" arguments ")" -> invoke
       | "break" -> break_

?compound: "repeat" expr "as" NAME ":" suite -> repeat
         | "for" target "in" expr ":" suite -> for_
         | "if" expr ":" suite elif* ["else" ":" suite] -> if_
         | "while" expr ":" suite -> while_
         | "at" expr ":" suite -> at
         | "pattern" NAME "(" parameters ")" ":" suite -> pattern

elif: "elif" expr ":" suite
target: NAME | "(" NAME ("," NAME)+ ")"
parameters: (NAME ("," NAME)* ","?)?
suite: _NL _INDENT statement+ _DEDENT

?expr: or_test
     | or_test "if" or_test "else" expr -> conditional
?or_test: and_test ("or" and_test)*
?and_test: not_test ("and" not_test)*
?not_test: "not" not_test -> not_
         | comparison
?comparison: sum (compare_op sum)*
?sum: product (sum_op product)*
?product: unary (product_op unary)*
?unary: "-" unary -> negative
      | "+" unary -> positive
      | postfix
?postfix: atom
        | postfix "." NAME -> attribute
        | postfix "[" expr "]" -> index
        | NAME "(" arguments ")" -> call

arguments: (argument ("," argument)* ","?)?
?argument: expr
         | NAME "=" expr -> keyword

?atom: NUMBER -> number
     | DURATION -> duration
     | ANGLE -> angle
     | STRING -> string
     | "true" -> true
     | "false" -> false
     | NAME -> name
     | "(" expr ")"
     | "(" expr "," (expr ("," expr)* ","?)? ")" -> tuple
     | "[" (expr ("," expr)* ","?)? "]" -> list

!compare_op: "<" | ">" | "==" | "!=" | "<=" | ">=" | "in" | "not" "in"
!sum_op: "+" | "-"
!product_op: "*" | "/" | "//" | "%"
!update_op: "+=" | "-=" | "*=" | "/=" | "//=" | "%="

ORDER: "chronological" | "as-written"
STRING: /"(?:[^"\\\n]|\\.)*"/
DURATION.2: /(\d+\.\d*|\.\d+|\d+)(ms|s)\b/
ANGLE.2: /(\d+\.\d*|\.\d+|\d+)deg\b/
NUMBER: /0[xX][0-9a-fA-F]+|(\d+\.\d*|\.\d+|\d+)([eE][+-]?\d+)?/
INT: /\d+/
NAME: /[A-Za-z_]\w*/
_NL: /(\r?\n[\t ]*|#[^\n]*)+/
```

Indent with spaces. Brackets may span lines; nothing else continues a line. `#` starts a comment.

## Semantics the grammar leaves out

- **Time and angles.** Every `spawn`/`burst`/`place` must execute inside an `at` block, directly or through a pattern called inside one, or compilation fails. `at t:` is absolute: it never means "after the previous block". Advance a `var` cue to sequence. `500ms`/`2s`/`2.5s` resolve to integer ms, and a bare number used as a time is ms. `90deg` resolves to radians, and bare angles are radians.
- **Directions.** The arena runs 0..1024 on both axes, y points down, north is y = 0, and `center` = (512, 512). Positions are allowed in -1024..2048, so off-screen arrivals are normal. In `polar`/`ring`/`arc`, angle 0 points east and positive angles turn clockwise on screen. `heading` 0 faces north. Heading only sets a creature's initial facing, since creatures steer toward the player at once. It does not rotate formations.
- **Bindings.** `let` is immutable and `var` is mutable. Assignment updates the nearest declared `var`. Block-local declarations shadow outer ones, and loop variables are fresh each iteration. Names starting with `_` are rejected. Settings must precede all statements.
- **Patterns.** Declare a pattern before you call it. A pattern sees its parameters and quest-level bindings, but not the caller's locals. It inherits the caller's `at` time and may contain its own `at` blocks. It cannot recurse or return a value, and a call is a statement, not an expression.
- **Values.** Values are numbers (64-bit-magnitude integers or finite floats), booleans, strings, immutable lists, points and template references. Points `+`/`-` with points and `*`/`/` with numbers, and `.x`/`.y` read them; a 2-tuple is a point wherever a point is expected. Lists have no arithmetic, comparisons apply to scalars or points, and `in` tests list membership. `range` takes Python arguments and excludes `stop`. `repeat N as i` gives `i` = 0..N-1. `while` is bounded only by the work budget.
- **Spawning.** `spawn T at P` takes one point or a list of points and emits one entry per point. `burst T at P copies N` is the single-point form, and `place T on Ps` is the list form. `copies` defaults to 1. A template reference is `family.alias` as listed below, or `template.<canonical_name_hex>` (e.g. `template.alien_small_gray_26`), or a bare native ID; templates 0x02 and 0x37 are rejected.
- **Order.** `order chronological` (the default) stable-sorts the table by trigger time. `order as-written` keeps emission order, which only matters for early-clear pulls and same-time adjacency.
- **Limits.** These are checked after construction: 1..256 entries; 1..384 copies per entry; at most 384 copies per trigger time and 8192 in total; trigger times 0..3,600,000 ms; title 1..64 printable ASCII characters; `author` 1..31. The compiler also caps source at 64 KiB, the parse tree at 10,000 nodes, nesting depth at 64, lists at 4,096 items and work at 100,000 units. Copies count template invocations: formations add their members, and nests keep producing.
- **Constants.** `center`, `arena_size` (1024), `pi`, `tau`, `players` (always 1), `hardcore` (always false).

Helper signatures. Parameters after `*` are keyword-only. Sides are `"north" | "south" | "east" | "west"`. Corners are `"northwest" | "northeast" | "southwest" | "southeast"`.

```text
point(x, y)
edge(side, *, outside=64, fraction=0.5)          # beyond an edge; fraction 0 = its west or north end
edge_line(side, count, spacing, *, outside=64)   # centred row along that edge, ascending x or y
opposite(side)
corner(name, *, outside=64)
corners(*, outside=64)                           # NW, NE, SW, SE
line(start, step, count)                         # start + step*i
ring(center, radius, count, *, start=0)          # start + i*tau/count
arc(center, radius, start, sweep, count)         # both ends included
polar(center, radius, angle)
facing(point, target)                            # heading from point toward target
rotate(points, angle, *, around=center)          # clockwise for positive angle
min(...), max(...), abs, int, float, len, range
rand()                                           # MSVCRT rand: 0..32767
rand_int(low, high)                              # inclusive; low + rand() % width
choose(items)                                    # items[rand() % len]
shuffle(items)                                   # Fisher-Yates; one draw per index from len-1 down to 1
```

- `terrain (a, b, c)`: three ground texture slots in 0..7, default `(0, 1, 0)`. The stock sets are `(0,1,0)`, `(2,3,2)`, `(4,5,4)` and `(6,7,6)`.
- `fixed_weapon true`: removes the `weapon` bonus, the `random_weapon` and `alternate_weapon` perks, and weapon drops.
- `no_weapons [...]`: any weapon in the table except `pistol`, removed from drops. Without it, every weapon can drop, since the ranked profile has every quest unlocked. While the player holds the Pistol, 3 kills in 4 try to drop a weapon pickup.
- `no_bonuses [...]`: any of `energizer` (enemies flee and can be eaten), `weapon`, `weapon_power_up`, `nuke`, `double_experience`, `shock_chain`, `fireblast`, `reflex_boost` (slow motion), `shield`, `freeze`, `medikit`, `speed`, `fire_bullets`. `points` can't be removed.
- `no_perks [...]`: any of `bloody_mess` (alias `quick_learner`), `sharpshooter`, `fastloader`, `lean_mean_exp_machine`, `long_distance_runner`, `pyrokinetic`, `grim_deal`, `alternate_weapon`, `plaguebearer`, `evil_eyes`, `ammo_maniac`, `radioactive`, `fastshot`, `fatal_lottery`, `random_weapon`, `mr_melee`, `anxious_loader`, `final_revenge`, `telekinetic`, `perk_expert`, `unstoppable`, `regression_bullets`, `infernal_contract`, `poison_bullets`, `dodger`, `bonus_magnet`, `uranium_filled_bullets`, `doctor`, `monster_vision`, `hot_tempered`, `bonus_economist`, `thick_skinned`, `barrel_greaser`, `ammunition_within`, `veins_of_poison`, `toxic_avenger`, `regeneration`, `pyromaniac`, `ninja`, `highlander`, `jinxed`, `perk_master`, `reflex_boosted`, `greater_regeneration`, `breathing_room`, `death_clock`, `my_favourite_weapon`, `bandage`, `angry_reloader`, `ion_gun_master`, `stationary_reloader`, `man_bomb`, `fire_caugh`, `living_fortress`, `tough_reloader`, `lifeline_50_50`. `instant_winner` can't be removed. Kills pay XP, and each level-up offers a perk.

## Creatures

The player has 100 HP, runs at 100 units/s, and walks through crowds; nests are solid. Creature speed 1 = 30 units/s, so speed 3.34 and up outruns the player. A creature bites within 30 units, at most once a second per creature, with no grace period between different biters. Enemy shots deal a flat 10. Creatures of size 30 or less die when they touch you and pay no XP. Most creatures curl in from a fixed compass bearing rather than beelining; *tight* ones curl closer and *chase* ones come straight at you.

A formation is one entry that brings a leader and linked followers. The last follower of every group except the bronze grid is a plain 20 HP alien. `alien_ring` starts stacked on the anchor and fans out; the small ring and the chains start spread up to about 250 units around it. ## Toolchain

You need uv (docs.astral.sh/uv). The game fetches its assets on first launch, with permission from the original developer.

```sh
uvx crimsonland@latest quest build my.quest
uvx crimsonland@latest quest play my.quest
uvx crimsonland@latest quest publish my.quest
```

- `build` compiles and prints the quest's ID, weapon, terrain, entry count and copies; errors name the line. `--json` prints the resolved table.
- `play` opens the game straight into the quest, and every attempt saves a replay.
- `publish` uploads the recipe with your newest clear of it as proof and prints its crimson.land/custom/<id> page.

- In a checkout (`gh repo clone banteg/crimson`), use `uv run crimson`. `python -m crimson.quests.dsl --stock 4.7` compiles any stock quest, and `--file` compiles a recipe with any `--seed`, `--players` and `--hardcore`.
- A quest's ID is a hash of its resolved table, title and settings. Any change to the recipe's output makes a new quest, and publishing it needs a fresh clear of that version. `--replay <file>` picks the proof clear, and `--name` sets the signing name.
- Replays and the signing key live in the per-user data dir: `~/Library/Application Support/banteg/crimsonland` on macOS, `%LOCALAPPDATA%\banteg\crimsonland` on Windows, `~/.local/share/banteg/crimsonland` on Linux. `CRIMSON_RUNTIME_DIR` overrides it. There are no accounts; `crimsonland identity export`/`import` move the key between machines.
- The browser (crimson.land/play) plays published quests only, from their pages.

## Examples

Nests to clear under a stream of native rings, closed by a boss (17 entries):

```text
quest "Clockwork" version 1
weapon assault_rifle
terrain (0, 1, 0)

let sockets = ring(center, radius=320, count=8)
let entrances = ["north", "east", "south", "west"]

pattern reinforcement(side):
    spawn formation.alien_ring at edge(side, outside=160)

repeat 8 as i:
    at 1s + i * 6s:
        spawn nest.alien_slow at sockets[i]
    at 3s + i * 6s:
        reinforcement(entrances[i % 4])

at 50s:
    spawn spider.boss at (768, 512)
```

Alternating ranged pressure and melee crowds on an accelerating cue, with a seeded deal of entrances (78 entries):

```text
quest "Crossfire" version 1
weapon shotgun
terrain (2, 3, 2)
no_bonuses [nuke]

let sides = shuffle(["north", "east", "south", "west"])
var cue = 2s
var gap = 9s

repeat 8 as wave:
    let side = sides[wave % 4]
    at cue:
        spawn spider.plasma at edge(opposite(side), outside=96, fraction=0.25 + 0.5 * (wave % 2))
        spawn spider.small_blue at edge_line(side, count=4 + wave, spacing=48) copies 1 + wave // 3
    at cue + 1500ms:
        spawn alien.fast at corner(choose(["northwest", "northeast", "southwest", "southeast"])) copies 2 + wave // 2
    cue += gap
    gap = max(gap - 700ms, 4s)

at cue + 2s:
    spawn spider.splitter at [edge("west"), edge("east")]
```

A rotating 60° escape gap through 12 closing rings (240 entries):

```text
quest "Closing Circle" version 1
weapon plasma_rifle
terrain (6, 7, 6)

repeat 12 as wave:
    let gap_start = wave * 30deg
    at 2s + wave * 5s:
        spawn alien.small_gray at arc(center, radius=480 - wave * 18, start=gap_start + 60deg, sweep=300deg, count=20)
```
