# Crimsonland custom quests (`.quest`): reference for LLMs

Give this file to an LLM and describe the encounter you want. The LLM writes a `.quest` recipe; you play it, beat it, and publish it to crimson.land.

## 0. Context

- Crimsonland (10tons, 2003) is a top-down arena shooter. Its quests are fixed timelines of enemy arrivals; a quest is won by killing everything after the last arrival.
- github.com/banteg/crimson rebuilds the 1.9.93 release as a Python game (`crimsonland` on PyPI, command `crimson`) and as recovered C/C++ compiled to WebAssembly, which plays at crimson.land/play.
- A custom quest is a recipe in the `.quest` language. It runs once, before play, and emits a table of spawns using the original game's enemy templates. It cannot add enemies, change their behaviour or script anything during play.
- Published quests live at crimson.land/custom, each with its own page at crimson.land/custom/<id>: a preview, a leaderboard, the proof clear and the recipe. Anyone can play a published quest in the browser from its page.

## 1. Instructions for the LLM

- Output one recipe in a single ```` ```text ```` code block, then a few lines on how it plays (weapon, threats, rough length).
- Use only the syntax, helpers, names and templates in this file. Unknown names are compile errors.
- Indent blocks with 4 spaces. Use plain ASCII. Comments start with `#`.
- Aim for a quest a decent player can clear: one that lasts 1 to 5 minutes, ramps up, and leaves the player room to move. Players must beat a quest before publishing it, so an impossible quest never ships.
- Count entries as you go: every point a `spawn` lands on is one entry, and the table holds at most 256.
- If the user reports a compile error, it names a line: fix that line and return the whole recipe again.

## 2. Install, play, publish

Install uv (https://docs.astral.sh/uv/getting-started/installation/). Nothing else is needed: the game downloads its assets on first launch, with permission from the original developer.

```sh
# 1. Check the recipe compiles; prints its ID, weapon, terrain and entry count
uvx crimsonland@latest quest build my.quest
uvx crimsonland@latest quest build my.quest --json   # the resolved spawn table

# 2. Play it; the game opens straight into the quest and saves a replay of every attempt
uvx crimsonland@latest --custom-quest my.quest

# 3. Publish the recipe with your newest clear of it as proof; prints the quest's page
uvx crimsonland@latest quest publish my.quest
```

- From a checkout (`gh repo clone banteg/crimson && cd crimson`), `uv run crimson` replaces `uvx crimsonland@latest`. The 14 examples in `src/crimson/quests/dsl/examples/` and recipes for all 50 stock quests in `src/crimson/quests/dsl/stock/` are worth reading.
- `--windowed`, `--width 1024 --height 768` set the window. Custom quest runs always play the ranked profile: one player, a fresh save, no hardcore, fixed bugs.
- Replays, saves and your key live in the per-user data directory: `~/Library/Application Support/banteg/crimsonland` on macOS, `%LOCALAPPDATA%\banteg\crimsonland` on Windows, `~/.local/share/banteg/crimsonland` on Linux. `CRIMSON_RUNTIME_DIR` or `--base-dir` moves it.
- `quest publish` needs a completed run of exactly this recipe. The quest ID is the first 12 hex digits of a hash of the resolved table, title and settings: any change to the recipe's output makes a new quest that needs a new clear. `--replay <file>` picks a specific clear, `--name` the name it is signed with.
- There is no account. The game makes a signing key on first launch; `crimsonland identity show` prints it and `identity export`/`import` move it to another machine.
- Playing a recipe needs the installed game; the browser plays only published quests.

## 3. How a quest runs

- The recipe emits a table of `1..256` entries. Each entry is a template, a position, a heading, a trigger time and a copy count.
- The arena is `0..1024` on both axes, with `center` at `(512, 512)`; `y` grows downward (north is `y = 0`). Positions may lie anywhere in `-1024..2048`, so enemies can arrive from off screen. `edge()` and `corner()` default to 64 units outside the arena.
- Copies of one entry spread out in a line, 40 units apart on alternating sides (offsets 0, -40, +80, -120, ...): along `x`, or along `y` when the position is off the west or east side.
- Each frame the game spawns the first due entry in table order, together with the entries right after it that share its exact trigger time. Same-time entries split by another time arrive a frame apart.
- Once the arena has been empty for 3 seconds (and at least 1.7 s have passed), the next remaining entry spawns early, whatever its time. Fast players pull the timeline forward this way.
- The quest is won when every entry has spawned and no creature is alive, nests included. There is no time limit and no other objective.
- Limits: `1..256` entries; `1..384` copies per entry; at most `384` copies sharing one trigger time and `8192` in total; trigger times `0s..3600s`. Copies count template invocations, not creatures: formations bring their members and nests keep spawning.
- Compiler budget: 64 KiB of source, 10,000 syntax nodes, 4,096 items per list, 100,000 work units.
- Custom quests build with `players = 1`, `hardcore = false` and construction seed 0, so `rand()` gives the same table every time.

## 4. Header and settings

The first line is `quest "Title" version 1` (title: 1..64 printable ASCII characters). Optional settings follow, in any order, before the first statement:

```text
quest "Crosswind" version 1
author "banteg"
weapon shotgun
terrain (2, 3, 2)
order chronological
fixed_weapon true
no_bonuses [nuke, freeze]
no_perks [poison_bullets, plaguebearer]
no_weapons [ion_cannon, plasma_cannon]
```

- `author "Name"`: byline under the title, 1..31 printable ASCII characters.
- `weapon <name>`: starting weapon, default `pistol`. Any of:
  `pistol`, `assault_rifle`, `shotgun`, `sawed_off_shotgun`, `submachine_gun`, `gauss_gun`, `mean_minigun`, `flamethrower`, `plasma_rifle`, `multi_plasma`, `plasma_minigun`, `rocket_launcher`, `seeker_rockets`, `plasma_shotgun`, `blow_torch`, `hr_flamer`, `mini_rocket_swarmers`, `rocket_minigun`, `pulse_gun`, `jackhammer`, `ion_rifle`, `ion_minigun`, `ion_cannon`, `shrinkifier_5k`, `blade_gun`, `spider_plasma`, `evil_scythe`, `plasma_cannon`, `splitter_gun`, `gauss_shotgun`, `ion_shotgun`, `flameburst`, `raygun`,
  and the secret weapons `plague_spreader_gun`, `bubblegun`, `rainbow_gun`, `grim_weapon`, `fire_bullets`, `transmutator`, `blaster_r_300`, `lightning_rifle`, `nuke_launcher`.
- `terrain (a, b, c)`: three terrain texture slots in `0..7`, default `(0, 1, 0)`. The classic sets are `(0, 1, 0)`, `(2, 3, 2)`, `(4, 5, 4)` and `(6, 7, 6)`.
- `order chronological | as-written`: `chronological` (default) sorts entries by trigger time, keeping emission order for ties. `as-written` keeps emission order, so early clears pull entries forward in that order.
- `fixed_weapon true | false`: lock the player to the starting weapon. Disables the `weapon` bonus, the `random_weapon` and `alternate_weapon` perks, and weapon drops.
- `no_bonuses [...]`: bonuses that never drop. Any of:
  `energizer`, `weapon`, `weapon_power_up`, `nuke`, `double_experience`, `shock_chain`, `fireblast`, `reflex_boost`, `shield`, `freeze`, `medikit`, `speed`, `fire_bullets`. (`points` always drops.)
- `no_perks [...]`: perks never offered. Any of:
  `bloody_mess` (or `quick_learner`), `sharpshooter`, `fastloader`, `lean_mean_exp_machine`, `long_distance_runner`, `pyrokinetic`, `grim_deal`, `alternate_weapon`, `plaguebearer`, `evil_eyes`, `ammo_maniac`, `radioactive`, `fastshot`, `fatal_lottery`, `random_weapon`, `mr_melee`, `anxious_loader`, `final_revenge`, `telekinetic`, `perk_expert`, `unstoppable`, `regression_bullets`, `infernal_contract`, `poison_bullets`, `dodger`, `bonus_magnet`, `uranium_filled_bullets`, `doctor`, `monster_vision`, `hot_tempered`, `bonus_economist`, `thick_skinned`, `barrel_greaser`, `ammunition_within`, `veins_of_poison`, `toxic_avenger`, `regeneration`, `pyromaniac`, `ninja`, `highlander`, `jinxed`, `perk_master`, `reflex_boosted`, `greater_regeneration`, `breathing_room`, `death_clock`, `my_favourite_weapon`, `bandage`, `angry_reloader`, `ion_gun_master`, `stationary_reloader`, `man_bomb`, `fire_caugh`, `living_fortress`, `tough_reloader`, `lifeline_50_50`. (`instant_winner` is always offered.)
- `no_weapons [...]`: weapons that never drop. Any weapon from `assault_rifle` to `raygun` in the list above.

## 5. Statements

```text
let sockets = ring(center, radius=320, count=8)
var cue = 2s

pattern wave_pair(side, n):
    spawn spider.small_blue at edge_line(side, count=6 + n, spacing=36)
    spawn spider.plasma at edge(opposite(side), outside=128) copies 2

repeat 6 as i:
    at cue:
        wave_pair(["west", "east"][i % 2], i)
    cue += 6s
```

- `let name = expr` binds an immutable value. `var name = expr` declares a mutable one, updated with `=`, `+=`, `-=`, `*=`, `/=`, `//=`, `%=`.
- `at <time>:` sets the absolute trigger time of the spawns inside it. It never means "after the previous block"; use a `var` to advance a cue.
- `spawn <template> at <point or list of points> [copies N] [heading <angle>]` emits one entry per point. `copies` defaults to 1, `heading` (initial facing) to 0.
- `burst <template> at <point> copies N` and `place <template> on <points> [copies N]` are aliases of `spawn`.
- `repeat N as i:` runs with `i` from 0 to N-1. `for x in items:` and `for (x, y) in items:` iterate a list or `range(...)`.
- `if cond:` / `elif cond:` / `else:`, `while cond:` and `break` work as in Python.
- `pattern name(args):` declares a reusable block; call it as a statement, `name(args)`. Declare patterns before use. They see their parameters and quest-level bindings, inherit the caller's `at` time, may hold their own `at` blocks, and cannot recurse or return values.
- Every spawn, and every pattern call that spawns, must sit inside an `at` block (directly or through the caller); use `at 0s:` for the opening wave.

## 6. Values and expressions

- Numbers, `true`/`false`, double-quoted strings, immutable lists `[a, b, c]`, points and template references. There is no dict and no list mutation.
- Times: `500ms`, `2s`, `2.5s`; a bare integer used as a time is milliseconds. Angles: `90deg`; a bare number used as an angle is radians.
- Operators: `+ - * / // %`, unary `-`, comparisons, `and`, `or`, `not`, `in`, `not in`, indexing `items[i]`, and `a if cond else b`.
- Points add and subtract, and scale by numbers (`center + point(0, 200)`, `start + step * 2`). `.x` and `.y` read their coordinates. Lists have no arithmetic.
- `range(start, stop, step)` stops before `stop`. Names starting with `_` are not allowed.

## 7. Constants and helpers

- Constants: `center` (`(512, 512)`), `arena_size` (`1024`), `pi`, `tau`, `players` (always 1), `hardcore` (always false).
- Geometry (points are `point(x, y)` or `(x, y)`; sides are `"north"`, `"south"`, `"east"`, `"west"`):
  - `edge(side, outside=64, fraction=0.5)`: a point beyond an edge; `fraction` slides it along the edge.
  - `opposite(side)`: the opposite side.
  - `edge_line(side, count, spacing, outside=64)`: `count` points centred along an edge, in ascending `x` (north/south) or `y` (west/east).
  - `corner(name, outside=64)`: a point beyond `"northwest"`, `"northeast"`, `"southwest"` or `"southeast"`.
  - `corners(outside=64)`: all four, in NW, NE, SW, SE order.
  - `line(start, step, count)`: `count` points from `start`, each one `step` further.
  - `ring(center, radius, count, start=0)`: `count` points evenly around a circle, clockwise on screen.
  - `arc(center, radius, start, sweep, count)`: `count` points along an arc, both ends included; positive sweep is clockwise.
  - `polar(center, radius, angle)`: one point on a circle.
  - `facing(point, target)`: the heading from `point` toward `target`.
  - `rotate(points, angle, around=center)`: the points rotated clockwise for a positive angle.
- Math: `min(...)`, `max(...)` (numbers or one list), `abs(x)`, `int(x)`, `float(x)`, `len(items)`, `range(...)`.
- Seeded randomness, fixed per quest: `rand()` (0..32767), `rand_int(low, high)` (inclusive), `choose(items)`, `shuffle(items)` (returns a new list).

## 8. Creature templates

Templates are the original game's spawn templates. Each keeps its native health, speed, AI and offspring.

- Aliens: `alien.small_gray`, `alien.fast`, `alien.small_green`, `alien.green`, `alien.purple`, `alien.big_gray`, `alien.gray_fast`, `alien.boss`, `alien.cyan`, `alien.ghost`, `alien.bonus_carrier` (drops a weapon bonus), `alien.delayed`, `alien.flanker`, `alien.spawner_ring`, `alien.random`
- Spiders: `spider.small_blue`, `spider.plasma` (shoots plasma), `spider.splitter` (splits when killed), `spider.boss`, `spider.red_boss`, `spider.white_fast`, `spider.small_brown`, `spider.stop_and_go`, `spider.stop_and_go_weak`, `spider.flanker`, `spider.random`, `spider.random_red`, `spider.random_green`
- Lizards: `lizard.gray`, `lizard.boss`, `lizard.flanker`, `lizard.random`
- Zombies: `zombie.random`, `zombie.small_white`, `zombie.brute`, `zombie.spawner_boss`
- Nests, stationary spawners that keep producing creatures until destroyed: `nest.alien`, `nest.alien_slow`, `nest.alien_weak`, `nest.spider`, `nest.plasma`, `nest.spider_weak`, `nest.lizard`, `nest.lizard_slow`
- Formations, one entry that brings a linked group: `formation.alien_ring`, `formation.alien_ring_small`, `formation.alien_chain`, `formation.lizard_chain`, `formation.alien_grid`, `formation.alien_grid_green`, `formation.alien_grid_bronze`, `formation.lizard_grid`, `formation.spider_grid`

`place alien.small_gray on ring(...)` makes independent enemies; `spawn formation.alien_ring at ...` makes the original linked ring. Rotating a position does not rotate a formation's members.

## 9. Examples

### Fixed-weapon trial
```text
quest "Shotgun Trial: Split Decision" version 1
author "banteg"
weapon shotgun
terrain (4, 5, 4)
fixed_weapon true
no_bonuses [nuke, freeze]

repeat 5 as wave:
    let side = ["west", "north", "east", "south"][wave % 4]
    at 2s + wave * 10s:
        spawn spider.splitter at [edge(side), edge(opposite(side))]
    at 6s + wave * 10s:
        spawn spider.small_blue at edge_line(side, count=6 + wave * 2, spacing=32)
        spawn alien.fast at edge(opposite(side), outside=128) copies 2 + wave
```

### Nests under reinforcement
```text
quest "Clockwork" version 1
weapon assault_rifle
terrain (0, 1, 0)

let sockets = ring(center, radius=320, count=8)
let entrances = ["north", "east", "south", "west"]

pattern reinforcement(side):
    spawn formation.alien_ring at edge(side, outside=160)

repeat 8 as i:
    at 1s + i * 6s:
        spawn nest.alien_slow at sockets[i]
    at 3s + i * 6s:
        reinforcement(entrances[i % 4])

at 50s:
    spawn spider.boss at (768, 512)
```

### Rotating escape gap
```text
quest "Closing Circle" version 1
weapon plasma_rifle
terrain (6, 7, 6)

repeat 12 as wave:
    let gap_start = wave * 30deg
    at 2s + wave * 5s:
        spawn alien.small_gray at arc(center, radius=480 - wave * 18, start=gap_start + 60deg, sweep=300deg, count=20)
```
