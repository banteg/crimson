# Resurrecting Crimsonland

It has been twelve years since the last update on crimsonland.com. You'd think that's long enough for a game to rest in peace. You'd be wrong.

The original 2003 Crimsonland has been decompiled and rewritten from scratch. No source code was available, just the compiled binary and a healthy disregard for how long things are supposed to take. Two weeks and about 47,000 lines of code later, the game runs natively on modern platforms. All weapons, all perks, all game modes. Even the quest mode with its elaborate spawn sequences works as it should.

You can read the whole story over at [Resurrecting Crimsonland](https://banteg.xyz/posts/crimsonland/). It took 10tons about a year to port the game for the 2014 remaster. This time it took two weeks starting from the executable. Times have changed.
