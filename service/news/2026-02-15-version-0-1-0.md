# Version 0.1.0

The first proper release is out. Install [uv](https://docs.astral.sh/uv/getting-started/installation/), then one command fetches and runs it: `uvx crimsonland@latest`.

Everything is in there: the menus, Survival, Rush, all five tiers of quests, the tutorial, Typ-o-Shooter, every weapon, perk and creature, and even the secrets. The game is fully deterministic, so a run saves as a replay and plays back exactly as it happened. There's also a first go at co-op over a LAN.

Bug reports are very welcome. Stay tuned!
