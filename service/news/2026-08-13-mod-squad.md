# Mod Squad

Remember the Mods menu? In August 2003 10tons put out a MOD SDK for writing small games that ran inside Crimsonland. It came with two sample mods, one of them an Asteroids clone called CrimsonRoks, as both source code and compiled DLLs.

Twenty-three years later that turned out to be a gift. Building the SDK's source and comparing it with the DLLs it shipped with helps pin down exactly how 10tons built things back then.
