# Provider provenance

`jpeg_alloc_huff_table` from `jcomapi.obj`. Its object carries
`@comp.id=0x001d23da` (product 29, build 9178).

Stock VC6 `/O1 /G6 /W3 /GR- /MD` reproduces the function exactly and is used
here as a compatible local code-generation surrogate. The scratch compiler
selection is not a claim that VC6 produced the provider object.
