# Mechanics

How Crimsonland Classic plays, in numbers.

## Modes

- [Survival](modes/survival.md): endless waves, levels and perks; score is XP.
- [Rush](modes/rush.md): Assault Rifle only, no bonuses or perks; score is
  time.
- [Quests](modes/quests.md): scripted stages that unlock weapons and perks.
- [Typ-o-Shooter](modes/typo-shooter.md): type a creature's name to shoot it.
- [Tutorial](modes/tutorial.md): a short guided run.

## Combat

- [Player](combat/player.md): health, damage, movement, controls and death.
- [Creatures](combat/creatures.md): how each type moves and attacks, nests,
  bosses and XP.
- [Weapons](combat/weapons.md): fire rate, reload, damage and unlocks.

## Systems

- [Perks](perks.md): what each perk does and where it unlocks.
- [Bonuses](systems/bonuses.md): drop chances, durations and effects.
- [Co-op](systems/co-op.md): what players share and what each one keeps.
- [Scores and leaderboards](systems/scores.md): local tables and ranked play.
- [Secret weapons](secret-weapons.md): guns outside the normal quest unlocks.
- [Secrets](systems/secrets.md): the Secret Path, hidden controls and the
  console.

## Original bugs

The rewrite fixes some bugs in the original game by default. Pages note
them where they matter; `--preserve-bugs` restores the original behaviour.
[Classic quirks](systems/classic-quirks.md) lists them as a player meets
them; the full list is in [Original bugs](../rewrite/original-bugs.md).

For how the rewrite works, see the [rewrite](../rewrite/index.md). For the
evidence, see [reverse engineering](../re/index.md).
