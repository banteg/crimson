# Parity audit — 2026-06-12

Six parallel subsystem audits comparing the Ghidra decompile
(`analysis/ghidra/raw/crimsonland.exe_decompiled.c`, line refs below) against the
Python port. Known/intentional divergences documented in
`docs/rewrite/original-bugs.md` or gated behind `--preserve-bugs` were excluded;
everything listed here appears to be an **undocumented** divergence. Items are
suspected until validated against a Frida capture.

Subsystems covered: weapons, perks, creatures, bonuses/player, projectiles/collision/RNG,
modes/quests. Each section ends with what was verified clean, so coverage is close to
exhaustive for these subsystems rather than a sample.

---

## 1. RNG-stream desyncs (highest priority)

These shift the shared `crt_rand` stream during ordinary play, breaking determinism
against native captures.

### 1.4 `bonus_spawn_at` missing 16-particle burst (64 draws) + in-place corpse clamp

- **Native** `bonus_spawn_at` @ 0x41f5b0 (`.c:18231-18253`): always spawns 16 burst
  particles, 4 `crt_rand` draws each (rotation, vel_x, vel_y, scale_step). Sole caller is
  `creature_handle_death` (`.c:17503`) for flag-0x400 bonus-carrier creatures.
- **Port** `src/crimson/bonuses/pool.py:128-162` (`spawn_at`): no effects, no draws;
  `rng_caller_static.py` has no tag for any rand site in 0x41f5b0–0x41f78f.
- Additionally (`.c:18201-18211`) native clamps the position **through the pointer** —
  the dying creature's corpse moves to the 32-px world margin. The port clamps a copy
  (`pool.py:148-153`); `creature.pos` is never mutated.

### 1.5 Violence-disabled mode draws blood rands native skips

- **Native** `projectile_update` (`.c:19380-19412`): the whole splatter block — bloody-mess
  spread draws and the default `(rand & 7) == 2` reverse-splatter gate — is inside
  `if (config_violence_disabled == '\0')`. Violence off → zero draws.
- **Port** `src/crimson/sim/presentation_step.py:214-276`: both draws are unconditional;
  only `spawn_blood_splatter` itself is gated (`effects.py:816-817`). Violence off →
  2 (default) or 8 (Bloody Mess) extra draws per hit.

### 1.6 Poison Bullets gate skipped for creature-owned projectiles

- **Native** (`.c:19345-19348`): `perk_count_get(perk_id_poison_bullets)` reads a global;
  the `(rand & 7) == 1` draw fires for **every** projectile hit while anyone has the perk,
  including splitter children and shock-chain segments (creature owners).
- **Port** `src/crimson/projectiles/runtime/behaviors.py:72-77`: gated on
  `ctx.owner_perk_active(...)`, which is False for non-player owners
  (`projectile_pool.py:203-208`). Poison Bullets + Splitter Gun → permanent desync.

### 1.7 Freeze-shard vs burn-decal draw order swapped

- **Native** `projectile_update`: unconditional post-hit burn rand at `.c:19557`
  (caller 0x4215d2) executes **before** the freeze-shard branch at `.c:19628-19631`
  (caller 0x4215ff).
- **Port**: shard draws happen inside `step()` (`projectile_pool.py:493-507`), the burn
  later in `finish_hit_presentation` (`presentation_step.py:298`). Empirically confirmed;
  same count, values shift by one whenever Freeze is active.

### 1.8 Shrinkifier shrink-death rerouted through the damage pipeline

- **Native** (`.c:19508-19516`): `size *= 0.65; if (size < 16.0) creature_handle_death(...)`
  — direct death, no `creature_apply_damage`, no heading-jitter or death-SFX draws; health
  stays > 0 so the generic bullet damage right after still applies (drawing its own jitter).
- **Port** `behaviors.py:284-305` (`_post_hit_shrinkifier`): calls
  `_apply_damage_to_creature(hp + 1.0, damage_type=BULLET)` — full bullet path with extra
  jitter draw, perk multipliers, death-SFX roll, impulse; then the pool's generic damage is
  skipped because hp ≤ 0. Different draws and end state every shrink-kill.

### 1.9 Bandage skips dead players under `--preserve-bugs`

- **Native** `perk_apply` @ 0x4055e0 (`.c:4038-4052`): the per-player loop has **no alive
  check** — it draws `crt_rand()`, multiplies whatever the health is (including negative),
  and spawns the burst for every player slot.
- **Port** `src/crimson/perks/impl/bandage.py:9-13`: gates on `health > 0.0` in both
  modes. The default-mode gate is fine — original-bugs.md §3 already documents Bandage as
  an intentional fix ("heal each alive player") — but the `preserve_bugs` branch should
  replicate the native no-gate behavior: dead co-op partner → 1 missing draw + missing
  burst vs native. Also tighten the original-bugs.md §3 wording to note the native loop
  has no alive check.

### 1.10 Ordering items (conditional desyncs)

- **Spawner slot tick moved to loop tail** — native ticks the spawn slot inside the spawner
  movement branch (`.c:21746-21762`), before that creature's plaguebearer/anim/ranged/contact
  rand draws; port ticks it at the end of the per-creature body
  (`runtime.py:1290-1316`), and `skip_creature` paths skip the tick entirely.
- **Quest spawns fire after presentation planning** — quest is the only mode implemented as
  a `post_step` (`src/crimson/sim/sessions.py:260-264, 510-518`), running after
  `plan_world_presentation_step` (which consumes the same `state.rng`); native runs mode
  updates before render (`.c:6803-6828`). Draw order inverts on spawn ticks, plus a
  one-frame appearance delay.
- **Link-death self-damage bypasses `creature_apply_damage`** — native AI modes 4/5 call
  `creature_apply_damage(idx, 1000.0, 1, ...)` (`.c:21616-21645`) with type-1 pre-steps
  (jitter rand, hit flash) and a death-SFX roll; port does raw `hp -= 1000` +
  direct `handle_death` (`creatures/ai.py:178-194`, `runtime.py:1118-1144`). Fires on
  formation cleanup when a grid/ring boss dies (templates 0x14/0x15/0x17/0x19).
- **Secondary-rocket first hit misses the game-tune branch** — native plays
  `sfx_play_exclusive(music_track_extra_0)` (one playlist-pick rand) outside demo/rush
  (`.c:19862-19868`); port unconditionally queues `EXPLOSION_MEDIUM`
  (`secondary_pool.py:349-350`).

## 2. Gameplay-rule divergences

### 2.2 Quest timers tick with unscaled dt under Reflex Boost

- **Native** `gameplay_update_and_render` scales `frame_dt_ms` at entry
  (`.c:6714-6721`); `quest_mode_update` consumes the scaled value for the spawn timeline
  (`.c:4810`), the 3 s stall force-spawn (`.c:28803-28804`), and the 2.5 s completion
  transition. The timeline **is** the quest score, so Reflex Boost improves quest times.
- **Port** `src/crimson/sim/sessions.py:162` (`quest_post_step`): uses `dt_ms_i32`
  (unscaled) instead of `dt_sim_ms_i32`. Every other mode uses the scaled value
  (survival `sessions.py:133`, typo `typo/runtime.py:82`, tutorial `tutorial/runtime.py:58`).
  Reflex Boost is obtainable in quests (bonus suppression is rush-only, `.c:18213`).

### 2.3 Jinxed kill XP doubled under Double Experience

- **Native** `perks_update_effects` @ 0x406b40 (`.c:4780-4787`): single XP store, no
  `bonus_double_xp_timer` branch (contrast `creature_handle_death` `.c:17579-17597`).
- **Port** `src/crimson/perks/impl/jinxed_effect.py:33-34`: awards a second time when
  `double_experience > 0`. (The Radioactive kill path got this right.)

### 2.4 Energizer eat-kill missing the double XP award

- **Native** `creature_update_all` energizer branch: direct `exp += reward` **and**
  `creature_handle_death(idx, 0)` (creature still active → awards again). Native double-pays.
- **Port** `runtime.py:443-469` (`_creature_interaction_energizer_eat`): only
  `handle_death` (single award).

### 2.5 Swarmers fired with empty clip spawn 1 rocket instead of 0

- **Native** `player_update` (`.c:13490-13505`): `if (0.0 < player_ammo) { ... }` — with
  ammo ≤ 0 (reachable while firing during reload via Regression Bullets / Ammunition
  Within) **zero** rockets spawn, ammo unchanged.
- **Port** `src/crimson/weapon_runtime/fire.py:427`: `rocket_count = max(1, int(ammo))`
  always fires one and charges `ammo_cost = 1.0` (`fire.py:450`). Not covered by the
  documented swarmers spread bug (original-bugs §17) and diverges even with
  `--preserve-bugs`.

### 2.6 Thick Skinned floors health at 1.0

- **Native** `perk_apply` (`.c:3955-3963`): the `= 1.0` clamp fires only when
  `h - h*0.33333334 <= 0` — dead code for positive health; native leaves `2h/3`.
- **Port** `src/crimson/perks/impl/thick_skinned.py:11`: `max(1.0, health * 2/3)` —
  for `0 < health < 1.5` the port **raises** health (e.g. Infernal Contract's 0.1 HP →
  1.0 vs native ~0.067). Secondary nit: f64 `2/3` without an `f32()` spill.

### 2.7 Homing target search capped at 1000 units (squared/linear mixup)

- **Native** `creature_find_nearest` @ 0x420040 (`.c:18699-18714`): initial best 1e6
  compared against the **plain** distance — effectively unlimited.
- **Port** `src/crimson/projectiles/runtime/collision.py:61-74`: `best_dist_sq = 1_000_000`
  vs `distance_sq` — a 1000-unit cap. Seeker rockets can fail to acquire far targets.
  The same predicate in `bonuses/shock_chain.py:24` correctly uses `1e12`.

### 2.8 Manual reload edge-triggered instead of level-triggered

- **Native** `player_update` (`.c:12766-12772`): uses `grim_is_key_active` (key **held**)
  with `reload_timer == 0.0` — holding reload chains reloads back-to-back.
- **Port** `src/crimson/gameplay.py:917-926`: uses `reload_pressed` (edge); one reload per
  press. (`reload_down` exists and is used for alt-weapon swap at `gameplay.py:953`.)

### 2.9 Simultaneous death + quest completion always fails in the port

- **Native**: no player-alive gate on the quest completion transition; death → QUEST_FAILED
  only after the death animation finishes (`.c:6834-6840`). Completion timer crossing
  2500 ms during the death animation → quest completes.
- **Port** `sessions.py:189-203`: completion only ticks while `any(health > 0)`, else the
  timer resets to −1; dying with the last kill always yields the failed screen.

## 3. Co-op / friendly-fire only

### 3.1 Friendly fire unreachable for primary projectiles

- **Native** `projectile_update` (`.c:19327-19341`): only `owner == -100` skips
  `player_find_in_radius`; with `cv_friendlyFire`, weapon fire uses
  `owner = -1 - player_index` (`.c:13044-13048`) and can hit the other player for 10.
- **Port**: player-hit branch requires `proj.hits_players`
  (`projectile_pool.py:368`), which weapon fire never sets (`weapon_runtime/spawn.py:105`);
  unreachable even with `state.friendly_fire_enabled = True`. (Shock-chain segments are
  not affected: native skips `player_find_in_radius` for the tracked
  `shock_chain_projectile_id` (`.c:19323`) and re-tracks each new chain segment on spawn
  (`.c:19465`).)

### 3.2 Same-frame co-op bonus pickup applied once

- **Native** `bonus_update` @ 0x40a320 (`.c:6495-6509`): no break in the player loop —
  both players in the 26-unit radius trigger `bonus_apply` the same tick (nuke detonates
  twice, both consume RNG, Points credited twice).
- **Port** `src/crimson/bonuses/pool.py:392-419`: `break` after the first in-range player.

### 3.3 Radioactive aura measured from player 1, missing hp gate

- **Native** `creature_update_all` (`.c:21801-21841`): pulse distance is creature →
  **target player** (`target_player * 0x360` indexing), and the timer-fire requires
  creature `hp > 0`.
- **Port** `runtime.py:1201-1219`: always `players[0]` for both the perk check and the
  distance, no hp gate (a plague-killed creature can pulse again the same tick). XP credit
  to player 1 matches native.

### 3.4 Player-1 substitution / gating nits

- Plaguebearer contact-flag step missing native `size > 16` and `player.health > 0` gates,
  plus a rewrite-only alive early-return (`runtime.py:542-554`).
- Dodged hit on an already-dead player: native still decrements the death-animation timer
  (`.c:21305-21343` falls through to the health branch); port gates on `not dodged`
  (`player_damage.py:96`). Edge case, cosmetic.
- Auto-target feedback: port filters dead creatures / dead current targets where native
  doesn't (`runtime.py:695-728`); native consumer re-scans, so low impact.

## 4. Stats, cosmetic, float-parity

### Stats

- **Flamethrower-family inflates `shots_fired`** — native increments only in
  `projectile_spawn` (`.c:18891`) and `fx_spawn_secondary_projectile` (`.c:18852`);
  particle weapons (Flamethrower 8, Blow Torch 0xf, HR Flamer 0x10, Bubblegun 0x2a)
  never count. Port adds every fire tick (`fire.py:453-456`) — ~125/s for the
  flamethrower, wrecking the accuracy stat.
- **`shots_hit` requires a player owner** in the port (`projectile_pool.py:413-416`);
  native counts any hit on a `hitbox_size == 16.0` creature (`.c:19413-19415`).
- **Quest final-time math**: port uses `round(health)` vs native `__ftol` truncation, and
  clamps `final_ms < 1` where native keeps negatives and only remaps exact 0 → 1
  (`src/crimson/quests/results.py:74-86` vs `.c:10374-10387`). Highscore-affecting, tiny.

### Cosmetic

- **Muzzle-smoke velocity rotated 90°** — native uses raw `(cos h, sin h)` of the aim
  heading (`.c:13117-13120`), i.e. perpendicular to the aim; port uses
  `Vec2.from_heading` (aim direction) at `weapon_runtime/fire.py:123`. The Fire Cough and
  shell-casing ports use the correct native convention (`from_angle`).
- **Rocket trail cos/cos bug not preserved** — native derives both velocity components
  from cosine (`.c:19800-19803`); port uses cos and sin (`secondary_pool.py:316`). The
  analogous primary-pool impulse bug *was* preserved.
- **Evil Eyes frozen target keeps animating** — native halts anim-phase for the frozen
  creature (advance is inside `if (idx != evil_eyes_target)`); port advances all
  (`sim/world_state.py:547-565`).
- Sprite-effects vs particles update order inverted (`world_state.py:358-365` vs
  `.c:19989-20006`); particle-spawned sprites advance one frame early. No RNG impact.
- `FxQueue.add_random` alpha 1.0 (`effects.py:543`) vs native persisted ~0.78 (`.c:22056`).
- Eat-range movement revert adds a bounds clamp native lacks (`runtime.py:429-434` vs
  `.c:21850-21854`).
- Quest builders drop native integer truncation of computed spawn coordinates
  (e.g. `.c:31211-31218` Target Practice, `.c:29737-29741` Spanking of the Dead) —
  port keeps full floats (`quests/tier1.py:142`, `tier5.py:133-139`). Sub-pixel.

### Float-parity policy violations (1-ulp class)

- Fireblast ring: `math.tau / 16` (f64) vs native f32 literal `0.3926991`
  (`weapon_runtime/spawn.py:154-160`); differs at indices 5, 7, 10, 11, 14 of 16.
- Shock-chain spawn/initial heading: `to_heading()` (atan2 + π/2) vs native
  `atan2 − π/2 − π` (`bonuses/shock_chain.py:38`, `behaviors.py:230` vs `.c:6314-6319`,
  `.c:19470-19476`) — same direction mod 2π but different stored f32 angle → different
  f32 velocities (~89% of headings differ by 1 ulp).
- Heading-jitter clamp: f64 `math.pi/2` + no `f32()` spill (`creatures/damage.py:130-132`
  vs `.c:19120-19125`).
- Stop-on-hit jitter: double rounding vs native single spill (`projectile_pool.py:431-436`
  vs `.c:19446`).
- Secondary pool runs f64 with no `f32()` store points (`secondary_pool.py:263,273`);
  seeker steering restructured (native add-then-maybe-subtract in f32 is not an identity,
  `.c:19768-19790`). Accumulated drift will shift hit ticks and therefore RNG.
- Constant drift: `size * (2.0/21.0)` vs f32 `0.0952381` (`spawn.py:1225`, feeds
  `reward_value` → XP off-by-one possible); split children `reward * (2.0/3.0)` vs f32
  `0.6666667`, double `math.pi/2` offsets + extra `_wrap_angle`, `target_heading` set to
  child heading vs native stale parent copy (`runtime.py:1602-1616`).
- Particle deflection wrap: Python `% math.tau` vs native iterative wrap with f32
  `6.2831855`; feeds the `angle <= hit_angle` branch boundary (`effects.py:318-328` vs
  `.c:20111-20120`).
- Inclusive vs strict radius acceptance in ion linger / particle search
  (`behaviors.py:113`, `effects.py:212` use `<=`; native and `collision.py:46-49` are
  strict).

### Edge / latent

- Pulse-gun knockback doesn't `sync_index` the spatial hash (`behaviors.py:308-310`) —
  later projectiles the same tick can miss the pushed creature at bucket boundaries
  (native re-scans the pool per query).
- Rocket TTL: strict `speed < 0.0` vs native `<= 0.0`, and native's post-hit TTL block can
  overwrite a same-tick hit's detonation scale to 0.5 (`secondary_pool.py:517-524` vs
  `.c:19980-19984`).
- Batch `plan_hit_sfx` caps hit-SFX rand draws at 4 hits/frame
  (`presentation_step.py:110`); native draws per hit, uncapped (`.c:19641-19644`).
  Only affects callers without precomputed `hit_sfx`.
- `weapon_assign_player` port resets `reload_active`/`reload_timer_max` that native
  leaves stale (`weapon_runtime/assign.py:75-77` vs `.c:50910-50915`).
- Weapon-bonus + Alternate Weapon "stash into empty alt slot" branch has no native
  counterpart (`bonuses/weapon.py:13-24`); dead code since the pistol alt-slot preload
  (commit `abb2ca37`) but native-impossible if ever reached.
- Expired-then-picked bonus slot: native frees it immediately (`bonus_alloc_slot` checks
  only `bonus_id == NONE`, `.c:18177`); port keeps it blocked during the 0.5/3 s linger
  (`pool.py:45-52`). Observable only with all 16 slots full.
- Shot-jitter rounding sequence differs from native single-spill association
  (`fire.py:140-156` vs `.c:13055-13063`). Sub-ulp.

## Verified clean

- **RNG core**: `CrtRand` exactly matches the CRT LCG @ 0x461746 (multiplier 0x343fd,
  increment 0x269ec3, `>> 16 & 0x7fff`); seeding/masking/advance correct.
- **Weapon table** (`weapon_table_init` @ 0x4519b0 vs `weapons.py`): clip/cooldown/
  reload/spread/flags/ammo-class/travel/damage cross-checked across the full roster,
  including icon quirks and misspelled names behind `preserve_bugs`.
- **Per-weapon fire recipes**: pellet counts, jitter/speed RNG masks and call order,
  Multi-Plasma fan, casing draws, aim-jitter draws, SFX variant draw, muzzle-sprite
  ordering and alpha tables, cooldown/spread/ammo bookkeeping, reload paths
  (fastloader/anxious/stationary/angry).
- **Projectile pipeline**: `projectile_spawn` (fire-bullets override incl. double
  shots-fired quirk), 3-substep movement with f32 spill placement, damage formula
  `((100/max(50,d))*scale*30+10)*0.95`, pierce pool bookkeeping, ion AoE constants,
  shock-chain hop rules, secondary constants (accel caps, detonation scales, damage
  formulas, decal/shard counts), frame update order
  (`perks → effects → creatures → projectiles → player → modes → bonus timers`).
- **Perks**: choice generation (7-slot fill, Monster Vision force, Death Clock block-list
  sentinel, rarity gates, attempt escapes), `perk_can_offer` prereqs/flags, apply effects
  for ~30 perks (magnitudes, RNG order), player-damage perk chain, creature-damage
  multipliers.
- **Creatures**: `survival_spawn_creature` type tiers/rare rolls/stat formulas, AI modes
  0–8 target math, turn rates, anim multipliers, plague spread/tick, contact-damage flow,
  ranged-fire gates, death staging and `handle_death` ordering (apart from §1.2),
  radius-damage margin, spawn-slot timer semantics.
- **Bonuses**: drop-selection buckets (roll%162 mapping, fallbacks, suppression rules),
  effect magnitudes/durations × Bonus Economist, nuke/freeze recipes, pickup/decay
  rules, `try_spawn_on_kill` (documented bugs gated), Telekinetic.
- **Modes**: survival wave pacing/milestones/weapon handouts, rush spawn cadence and
  stats, quest timeline interpreter, hardcore spawn-table adjustment, quest results reveal
  cadence, typo pacing, level-up thresholds.
- **Player**: movement/aim constants, XP curve, player damage chain incl. documented
  co-op bugs.
